# Fitme stop-word list: Russian (A§7, AGENTS.md §2 "Stop words halt the session").
#
# Same format and same "deliberately broad" rule as en.txt (see that file's header comment).
# `ё`/`е` are normalized to the same letter before matching (guards/stop_words/__init__.py),
# so a term spelled with either letter matches typing with the other one. This list is also
# checked against a Latin-transliterated reading of the input ("bolit" -> "болит"), so a
# lifter typing on a Latin keyboard is still caught.
#
# A line ending in `*` is a *stem*: it matches any word that starts with it, not just the
# exact phrase. Russian is heavily inflected (a pain/injury word appears in many forms:
# болит/больно/болел/...), so a curated set of stems covers this properly (A§7.1). Every stem
# below has a negative test in tests/guards/test_stop_words.py against a common, unrelated
# Russian word that happens to share the same first letters, proving the stem doesn't
# over-match. Stems are deliberately not used for *every* pain word (e.g. "бол-" is also
# "болото", a swamp, or "болтать", to chat) — those are covered by listing inflected forms
# explicitly instead.
#
# Chest/heart co-occurrence is handled in code, not here (A§7.1): `груд*`/`сердц*` halt only
# together with a symptom descriptor in the same clause ("в груди давит", "сердце колотится"),
# never on their own ("к верху груди", "на уровне груди", "лежа грудью на скамье", "день
# груди"). Only explicit cardiac terms that halt on their own belong in the chest_or_heart
# category below.
#
# Ordinary soreness ("крепатура", "забитые мышцы") and exertional breathlessness ("одышка")
# are intentionally excluded; only pain/dizziness/numbness/chest-or-heart/"something popped"/
# breathing-distress language halts. ("болит"/"больно" are still listed: they describe pain
# in the moment, which must halt, unlike a bare mention of expected next-day soreness.)
